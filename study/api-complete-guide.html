⚡ Reference Quick Reference Card Cheat sheet
⟶ Everything important on one card — HTTP methods, status codes, headers, parameters, Salesforce URLs
HTTP Methods
GET Read data, no body, safe
POST Create new data, has body
PUT Replace entire record, has body
PATCH Update part of record, has body
DELETE Delete record, no body
Status Codes
200 OK - Success
201 Created
400 Bad Request - Fix your data
401 Unauthorized - Check your token
403 Forbidden - Check permissions
404 Not Found - Check your URL
429 Rate Limited - Slow down
500 Server Error - Not your fault
Common Headers
Authorization: Bearer <token>
Content-Type: application/json
SF Quick Ref
SF REST Base URL: /services/data/v58.0/
SF Auth URL: login.salesforce.com/services/oauth2/token
